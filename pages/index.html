monokulo-lws for OpenWrt

A Monero light wallet server you run yourself, on your router, with its own LuCI page.

monokulo-lws scans the chain through your own monerod for every wallet registered with it, by the wallet’s private view key, and answers the light wallet REST API, so a wallet catches up in one request. Wallets keep their spend keys and sign on their own. This page is the signed apk repository for OpenWrt 25.12 and up, built from the source on every push to main.

Mainneton by default · node :18081 · wallet API :8443
Stagenetone switch away · node :38081 · wallet API :38443
Testnetone switch away · node :28081 · wallet API :28443

Each network turned on runs its own server, side by side, with its own node, ports, database and wallets. Turn them on and off in Services › Light Wallet Server › Networks.

Repositories

One per OpenWrt release and CPU architecture. Your router’s are in Status › Overview (Firmware Version and Architecture), or in a terminal: cat /etc/openwrt_release.

@REPOS@
OpenWrtArchitectureRepository

Install in LuCI

  1. Trust the signing key

    System › Administration › Repo Public Keys

    Paste the key (or its address, @PAGES_URL@/monokulo.pem) into the box and click Add key. It is the same key that signs monokulo’s and Kringle’s packages; if you trust it already, skip this.

    @PUBKEY@

  2. Add the repository

    System › Software › Configure apk

    In the box for /etc/apk/repositories.d/customfeeds.list, add the repository for your release and architecture from the table above on a line of its own, then Save.

  3. Install

    System › Software

    Click Update lists…, filter for monokulo-lws, and Install… it. The mainnet server starts at once, against a node at http://127.0.0.1:18081.

  4. Set it up

    Services › Light Wallet Server

    Reload LuCI for the new menu item. Under Networks, point each network at its node and tick On for the ones you want, then Save & Apply. Add wallets under Wallets, one network at a time.

Install over SSH

This picks your router’s release and architecture for you:

wget -O /etc/apk/keys/monokulo.pem @PAGES_URL@/monokulo.pem
. /etc/openwrt_release
echo "@PAGES_URL@/openwrt/${DISTRIB_RELEASE%.*}/$DISTRIB_ARCH/packages.adb" >> /etc/apk/repositories.d/customfeeds.list
apk update
apk add monokulo-lws

Turn stagenet on beside mainnet, against a stagenet node on this router:

uci set monokulo-lws.stagenet.enabled=1
uci set monokulo-lws.stagenet.daemon=http://127.0.0.1:38081
uci commit monokulo-lws
service monokulo-lws reload

Upgrade and remove

apk update && apk upgrade monokulo-lws

Settings, databases and admin keys are kept, and a firmware upgrade keeps them too. Settings from a version with one server move to the matching network’s section at the first start.

apk del monokulo-lws

Removal leaves /srv/monokulo-lws* (every wallet’s view key), /etc/monokulo-lws/ and /etc/config/monokulo-lws for you to delete.

Package files

Not needed if you use a repository. Signed with the same key, so once it is trusted they install directly: System › Software › Upload Package…, or apk add ./file.apk.
